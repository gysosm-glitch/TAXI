# 청주 택시 복합할증 계산기 · 합승 시뮬레이터

충북대학교 경영대 캡스톤. 청주시는 2026-09-28부터 **같은 읍·면 안의 운행만** 35% 복합할증을 해제했다. 수요가 가장 큰 **동↔오송·오창 구간은 여전히 할증**이고, 이 구간 해제는 2028년 검토 단계다. 이 프로젝트는 그 남은 할증을 데이터로 보여 주고, 두 가지 해법을 모바일 웹 데모로 제시한다.

1. **정책 시뮬레이터** — 할증 해제·인하 옵션별로 시가 부담할 보전비를 추정한다(시 발표 4억 원으로 보정).
2. **합승 시뮬레이터** — 2인만 합승해도 할증 구간 1인 부담이 할증 없는 단독요금보다 낮아진다는 것을 보여 준다.

> 본 데모는 합승 중개 서비스가 아닌 **정책·서비스 시뮬레이션**이다. 택시 합승은 등록된 플랫폼을 통해서만 허용되고, 중형 이하 택시는 동성끼리만 탈 수 있다. 사업화 시에는 등록 플랫폼 제휴 또는 ICT 규제샌드박스를 거친다.

## 폴더 구조

```
docs/      리서치 보고서(PDF·MD), 데이터 사전, Supabase·Vercel 설정 가이드
data/raw/  팀이 모은 원천 데이터 + 출처 기록(README)
data/web/  웹에서 쓰는 요소별 데이터 (01 존 ~ 08 확장)
scripts/   raw → web 데이터, Supabase seed 생성 스크립트
supabase/  schema.sql, seed.sql
src/       React 앱 (요금 엔진: src/lib/fare.js)
```

## 데이터 신뢰 등급

요금·보전비는 **보도 기준**, 통행량은 **공공데이터 추정**, 합승 요청 목록은 **합성 데이터**다. 정보공개청구 회신이 오면 교체할 위치는 데이터 사전에 정리했다.
