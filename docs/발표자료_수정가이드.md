# 쉐어택 발표자료 수정 가이드 (팀원용)

> **11/4 안내: 이 문서는 이전 구성(11/2)의 PPT용이다. 새 PPT는 캡스톤 폴더의 `쉐어택_PPT_작성가이드.docx`를 따른다.**

파일: `presentation/쉐어택_발표자료.pptx`. PowerPoint에서 바로 고치면 된다.

## 1. 고치기 전에: 글꼴 설치
`presentation/fonts/`의 `.ttf` 5개를 더블클릭해 **설치**한다(무료 글꼴, OFL). 설치하지 않아도 파일에 글꼴이 들어 있어 보기·발표는 되지만, 고칠 때는 설치해 두는 게 안전하다.

| 쓰임 | 글꼴 | 크기 |
|---|---|---|
| 장 제목, 큰 숫자, 카드 제목 | **Black Han Sans** (검은고딕) | 제목 30pt, 큰 숫자 24~36pt |
| 본문·표·설명 | **IBM Plex Sans KR** (굵게는 Bold) | 본문 12.5~15pt, 작은 설명 11pt 이상 |

검은고딕은 굵기가 하나뿐이라 **굵게(B)를 누르지 않는다**.

| 글자 | `#12201B` (본문), `#56655F` (설명) | |

## 3. 장마다 모양 (같은 모양을 반복하지 않게 만들었다)
| 장 | 모양 | 고칠 때 |
|---|---|---|
| 1 표지 | 미터기 + 아래 도로 위 정류장 = 목차 | 목차 이름은 정류장 아래 글자 |
| 2 페르소나 | 손님(밝은 카드) · 기사(어두운 카드), 아래 여정 도로 | 기사 쪽은 택시조합 인터뷰 요지와 자료 근거 문장 |
| 3 원인 | 어두운 화면 + 큰 숫자 46.5% | |
| 4 가치제안 | 지금의 불편 → 쉐어택 → 바뀌는 것 | 오른쪽 큰 숫자는 제목 글꼴 |
| 5 MVP | 앱 화면 + 3가지 경우 + 경쟁 비교 표 | 앱 화면은 그림이라 새로 캡처해 바꾼다 |
| 6 BMC | 9칸 + 아래 돈 흐름 | |
| 7 검증 | 왼쪽 설문(63%) · 오른쪽 미터기·표·그래프 | |
| 8 실행 | 4단계 화살표 + SWOT + 법·효과·한계 | |

- 아래쪽 점 8개는 "지금 몇 번째 장"을 나타낸다. 장 순서를 바꾸면 점 위치도 옮긴다.
- **미터기 숫자(35%, 46.5%, 63%, +5,774 등)는 그림**이다. 숫자를 바꿔야 하면 `presentation/bg3.js`의 `SEGS`를 고쳐 다시 만들거나, 그림을 지우고 제목 글꼴(호박색)로 숫자를 쓴다.
- 배경 그림(표지 야경, 8장 오송역)과 2장 그림은 실사 사진을 그림풍으로 바꾼 것. 출처는 화면에 넣지 않고 발표자 노트와 [사진_출처.md](사진_출처.md)에 있다.

## 4. 숫자·문장
- 숫자는 [자료_출처_정리.md](자료_출처_정리.md)에 있는 것만 쓴다. 모르는 값은 지어내지 말고 `[ ]`로 둔다.
- 장별 말할 내용은 각 장 **발표자 노트**와 [발표원고.md](발표원고.md).

## 5. 처음부터 다시 만들 때 (선택)
```
cd presentation
npm install && npm run art && node bg3.js && node photos.js && npm run build
powershell -ExecutionPolicy Bypass -File embed_fonts.ps1
```
※ 다시 만들면 PowerPoint에서 직접 고친 내용은 사라진다. 팀원이 손으로 고치기 시작한 뒤에는 PowerPoint 파일을 기준으로 한다.
