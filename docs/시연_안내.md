# 쉐어택 시연 안내

**접속**: https://taxi-woad-seven.vercel.app 또는 `캡스톤/발표자료/쉐어택_QR.png`. 로그인 화면에 시연 계정이 채워져 있어 **로그인**만 누르면 된다. 다음부터는 자동으로 들어간다.

**보여 줄 것**: 복합할증을 어떻게 줄이는가. 모집 칸과 기사 탭의 손님은 가상이고 '시연'으로 표시된다. 시간은 현재 시각을 따르고, 열차·버스는 실제 데이터다.

**영상**: `발표자료/쉐어택_시연영상.mp4` (한국어 음성, 전체 기능 설명)

## 순서
1. **타기**: 맨 위 카드에서 혼자 15,745원 → 2명 7,900원 → 귀로 면제 12,200원 비교
2. **모집 칸**: 오송역 → 터미널 칸에서 실제 KTX 도착에 맞춘 시간과 인원·조건 확인
3. **참여**: 칸 하나를 **참여** → 조건 확인 후 **탑승**
4. **대화**: 빠른 답장 한 번 누르기
5. **송금**: 인원이 차면 **송금 완료** → 방장이 택시 호출
6. **도착**: **도착** 누르고 절약 금액 확인
7. **교통**: 열차와 시내버스 실시간 정보, 출처와 확인 시각
8. **직접 모집**: 출발·도착 선택 → **모집 열기** → 가상 동승자가 참여하고 금액을 보냄 → **택시 호출** → **도착**
9. **기사**: 오송역 → **태우기** → 빈 차와 수입 비교. 지금 기능이 아니라 다음 단계의 가상 체험이라고 말한다 (연결 문장은 [발표원고](발표원고.md) 3페이지)

## 기사 가상 상황 활용
| 상황 | 보여 주는 것 | 발표에서 하는 말 |
|---|---|---|
| 귀로 손님 있음 | 핵심 효과: 빈 차 손실이 수입으로 바뀜 | 돌아가는 길에 손님을 태우면 기사도 이득입니다 |
| KTX 기다릴까 | 열차 정보가 기사의 판단을 돕는 모습 | 다음 열차를 보고 기다릴지 돌아갈지 정합니다 |
| 손님이 안 옴 | 노쇼 규칙: 할증분으로 손실 보전 | 약속을 어기면 기사 손해를 안 온 쪽이 메웁니다 (시범) |
| 손님이 없는 곳 | 서비스의 한계와 전략 근거 | 수요가 없는 곳은 앱도 못 채웁니다. 그래서 오송역부터 시작합니다 |
