# 같이타 청주 — 진행 현황

**앱:** https://taxi-woad-seven.vercel.app (휴대폰에서 열고 메뉴 › 홈 화면에 추가)

**한 줄:** 할증 붙는 택시비를 같은 방향 사람끼리 n분의 1로 나누는 앱

## 된 것 ✅
- 로그인·회원가입, **체험 계정 A·B**
- 같이타기: 모집 열기 · 참여 · 탑승 전 안내 · 도착 · 별점
- 실시간: 버스 도착 · 막차 · **오송역 KTX 도착**
- 알림: 참여 · 모집 완료 · 출발 10분 전
- 홈: 아낀 돈 · 시범 운영 현황
- 의견 보내기, 매일 자동 관리

## 1분 체험
1. 휴대폰 2대(또는 일반 창 + 시크릿 창)에서 앱 열기
2. 한쪽 **체험 계정 A**, 다른 쪽 **B**
3. A: 같이타기 › 오송역 › **새 모집 열기**
4. B: 그 모집에 **참여**
5. 둘 다 **도착했어요** → 홈에서 아낀 돈 확인
