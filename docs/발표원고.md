# 쉐어택 발표 원고 (PPT 8장)

> 최종 갱신 2026-11-06. 대상: `캡스톤/발표자료/쉐어택 캡스톤 발표(수정).pptx` (팀원 디자인본 위 수정, 발표자 노트에 같은 멘트).
> 숫자는 [자료_총정리.md](자료_총정리.md), 장별 검토 안내·출처·예상 질문은 [발표자료/참고자료.md](../../발표자료/참고자료.md)

**이름**: 쉐어택 = 쉐어(share) + 택시 · **팀**: 고경택시(오성민, 고경택, 이정재)
**한 줄**: 할증의 원인은 빈 차 귀로다. 귀로는 기사·호출앱·시가 다 필요해 바로는 못 하니, 손님 동승으로 수요부터 모으고(**1단계, 지금 앱**) 그 수요에 빈 차 귀로를 잇는다(**2단계, 제휴 후**).

## 구성
| 장 | 제목 | 메시지 |
|---|---|---|
| 1 | 문제 정의 | 할증은 줄어 왔지만 시내↔읍·면 35%는 남았고, 빈 차 손실을 손님에게 넘길 뿐이다 |
| 2 | 페르소나 · 인식 조사 | 세 사람이 실제로 있고, 설문과 에브리타임 글이 근거다 |
| 3 | 원인 분석 · 해결 방안 | 문제는 수요가 아니라 연결이다 → 동승·교통 정보(앱 구현) → 귀로(제휴 후) |
| 4 | 가치제안 캔버스 | 손님 불편 3개를 1:1로 푼다. 기사는 2단계에서 빈 차가 수입이 된다 |
| 5 | MVP | 이만큼 만들었고, 무엇이 실제이고 무엇이 시연용인지 표시했다 |
| 6 | 경영전략 | 기존 앱과 에브리타임 글 사이 빈자리. 위협에도 대응 전략이 있다 |
| 7 | 비즈니스 모델 캔버스 | 1단계 이용료 0원·시 실증 예산, 2단계부터 귀로 수수료·플랫폼 몫 |
| 8 | 사업성 검증 · 운영 계획 | 탈 사람·시장·수익을 근거로 보이고 2027~2028 단계별로 실행한다 |

## 1장 문제 정의
- 핵심 숫자: 하루 남은 할증 운행 **7,300건**(팀 집계) · 빈 차 **46.5%**(TIMS 2025) · 전면 폐지 시 **연 33억 원+**(시정연구원)
- 멘트: 올해 4월 청주시와 택시업계가 요금 개편 협약을 맺었고, 9월 28일부터 같은 읍·면 안 이동만 할증이 풀렸습니다. 하지만 시내와 읍·면을 오가면 여전히 35%가 붙고, 하루 약 7,300건입니다. 할증은 빈 차로 돌아오는 손실을 메우려고 생겼지만 청주 택시는 지금도 운행거리의 46.5%를 빈 차로 달립니다. 없애면 시가 연 33억 원 이상을 보전해야 합니다. 그래서 할증을 없애는 대신 그 원인인 빈 차 귀로를 줄이는 데서 출발했습니다.

## 2장 페르소나 · 인식 조사
- 핵심 숫자: 설문 57명(대학생 84%) **63%** 할증으로 포기 · **96%** 조건부 동승 · **93%** 할증 없으면 더 탐 · 오송역→터미널 혼자 15,745원 → 2인 각 **7,900원** · 에브리타임 오송역 동승 구인 **37건**(2학기)
- 멘트: 혼자 타면 비싼 대학생, 읍에서 출발해 할증이 붙는 직장인, 손님을 내려 주고 빈 차로 돌아오는 기사입니다. 설문에서 96%가 조건부로 동승하겠다고 했고, 두 명이면 한 사람 요금이 약 절반이 되어 대부분의 조건을 채웁니다. 실제로 2학기에만 에브리타임에 오송역 동승 구인 글이 37건 올라왔는데, 같은 시각 글이 따로 올라와 서로를 모릅니다. 기사 쪽은 10월에 택시조합과 기사 약 10명에게 물었고, 할증이 붙어도 수수료를 떼면 남는 게 적지만 폐지는 원하지 않았습니다.
- 주의: 직장인은 설문이 아니라 오창 승차 실측(2,617건)과 앱 요금 계산으로 만든 사례

## 3장 원인 분석 · 해결 방안
- 핵심 숫자: 100대당 시내행 손님 **89명** · 시간대를 맞추면 귀로 손님 최대 **82%**(팀 집계)
- 멘트: 시내행 손님은 충분하지만 시간이 엇갈리고, 지금 호출은 가까운 차 위주라 돌아가는 방향을 모릅니다. 문제는 수요가 아니라 연결입니다. 그래서 먼저 기사 앱 없이 거점 동승으로 요금을 나누고, 열차 도착 예정·버스 막차 정보로 시간을 맞추고, 제휴 후 내려 준 택시가 시내 손님을 태워 돌아오는 귀로 매칭으로 갑니다. 아래는 에브리타임 실제 글로, 각 말 아래에 앱의 답을 적었습니다.

## 4장 가치제안 캔버스
- 손님 핵심 Fit: 35% 할증 → 요금 n분의 1(각 7,900원) / 동승자 없음 → 거점 동승 모집 / 막차 끊김 → 막차·도착 정보 / 96% 조건부 동승 → 동성·번호 비공개·탑승 전 확인으로 안심 동승
- 기사(2단계): 빈 차 귀로 → 귀로 손님 연결 / 귀로 수입 → 참여 기사 하루 **+5,774원**(시뮬레이션). 조합이 원한 것은 할증 자체보다 **수입 유지**
- 멘트: 합승만 하면 기사 수입이 줄지만, 귀로 매칭이 붙으면 늘어납니다(시뮬레이션).

## 5장 MVP
- 흐름: 모집 보기 → 참여 → 시간 맞추기 → 대화로 약속 → **탑승 전 확인**(동성·번호 비공개 자동, 나머지 5개 직접) → 송금(방장은 택시 호출) → 도착 → 다음 단계(기사 체험)
- 표시: 초록 실제(요금 계산·공공데이터·대화·체크리스트) / 회색 시연용(모집·송금 약속·시뮬레이션) / 노랑 2단계 미리보기
- 멘트: 오른쪽 QR 두 개 중 왼쪽은 앱, 오른쪽은 약 2분 시연 영상입니다. 로그인만 누르고 타기에서 모집에 참여해 보시고, 교통 탭에서 오송역 KTX 도착을 확인해 보세요.
- 시연 순서는 [시연_안내.md](시연_안내.md)

## 6장 경영전략
- 포지셔닝: 카카오T·공공 택시앱은 가까운 차 호출에 할증 그대로, AI콜버스는 구간·시간 한정, 에브리타임 동승 글은 시간·장소가 안 맞으면 끝 → 쉐어택은 오른쪽 위
- SWOT: 기회에 에브리타임 37건·오송역 1,250만 명, 위협은 대형 호출앱의 동승 기능 직접 출시·2028 해제 검토 → ST "해제되면 B2G 도구로 전환"
- STP: 1차 오송역 KTX 이용 대학생(오송역 승차 중 시내행 52%, 추정) → 2차 오창 산단·터미널
- 멘트 끝: 무엇을 어디서 얼마에 제공하는지는 다음 장 BMC에서 이어서 보여 드립니다.

## 7장 비즈니스 모델 캔버스
- 멘트: 1단계인 지금은 손님이 동승으로 1인 요금을 약 절반으로 줄이고, 이용료는 0원이며, 운영비는 청주시 실증 사업으로 마련합니다. 오른쪽은 제휴 후 완성 모습입니다. 청주시가 귀로 운행 할증 4,301원을 면제하면 손님은 2,622원을 수수료로 기사에게 내고 1,679원을 아끼며, 기사 손해와 시 재정은 0입니다(B안, 앱 참여 30% 시뮬레이션). 주력 매출은 시와의 실증 사업·정책 데이터이고, 플랫폼 몫은 2단계입니다.

## 8장 사업성 검증 · 운영 계획
- 수요: 96% 조건부 동승 · 63% 할증으로 포기 · 에브리타임 37건
- 시장(하루): 청주 남은 할증 운행 **7,300건** → 오송역 시내 방향 **약 930건**(추정) → 오송 귀로 매칭 **36건**(시뮬레이션, 기사 앱 10%). 오송역은 연 1,250만 명
- 수익: 참여 기사 +5,774원(+1.86%), 전체 기사 수입 귀로 앱 30% +0.16% · 100% +0.50%. 쉐어택은 주력 B2G + 2단계 플랫폼 몫(2.8% 가정, 연 약 7,100만 원)
- 운영: ① 2027 상반기 오송역 시범(청주시 실증 사업, 동승은 등록 호출앱 제휴) ② 2027 하반기 귀로 실증 ③ 2028 거점 확대 ④ 2028~ 정책 연계(할증 유지 시 B안 건의 / 해제 시 B2G 데이터)
- 마무리: **빈 차 귀로를 채우면, 할증의 이유가 사라진다**
