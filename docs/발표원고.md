# 쉐어택 발표 원고 (PPT 8페이지)

> 최종 갱신 2026-11-04. 발표 내용의 기준이다. 숫자는 [자료_총정리.md](자료_총정리.md)에서 가져오고 바꾸지 않는다.
> 팀원용 제작 안내와 스케치: `캡스톤/쉐어택_PPT_작성가이드.docx`

**이름**: 쉐어택 = 쉐어(share) + 택시
**한 줄 소개**: 복합할증이 붙는 오송역·터미널 등 거점에서 같은 방향끼리 같이 타고, 귀로 서비스로 빈 차 문제까지 줄이는 플랫폼
**이야기 순서**: 할증이 부담된다 → 거점에서 같이 타면 줄어든다 → 버스·열차 정보로 이동이 편해진다 → 귀로 서비스로 빈 차까지 줄인다(핵심)
**팀**: 고경택시 · 경영정보학과 오성민, 고경택, 이정재 · **조사**: 시민 설문 57명(2026.10), 청주 택시조합 인터뷰(2026.11), 운행 자료 1,064만 건

## 1페이지. 문제 정의 — 같은 청주인데, 읍·면만 오가면 35%를 더 낸다
| 숫자 | 내용 | 출처 |
|---|---|---|
| **35%** | 동↔읍·면 복합할증. 시 설명 목적은 승차난 방지·공차 손실 보전 | 청주시 보도(2026.9) |
| **12.6%** | 9/28 개편 뒤에도 남는 할증 운행, 하루 약 7,300건 | 정보공개청구 팀 집계 |
| **67%** | 읍·면 관련 운행 중 오송·오창 | 정보공개청구 팀 집계 |
| **4,450원** | 충북대↔오송역 15km 혼자 탈 때 18,850원, 할증이 없으면 14,400원 | 쉐어택 앱 계산 |
- 9/28 개편: 같은 읍·면 안만 해제. 시내↔읍·면, 읍·면↔읍·면은 그대로
- 이해관계자: 손님 63%가 할증 때문에 택시 포기(설문) · 기사 운행거리 46.5%가 빈 차(TIMS 2025) · 시는 전면 폐지 시 연 33억 원 이상 보전 필요(청주시정연구원, 보도)
- 멘트: 할증을 없애도, 그대로 두어도 누군가는 손해를 봅니다. 그래서 할증의 원래 이유인 빈 차 귀로를 줄이자는 데서 출발했습니다.

## 2페이지. 페르소나 — 세 가지 상황과 기사
인물은 설명을 위한 가상 인물이고, 금액은 앱 계산값이다.
| 상황 | 누구 | 이동 | 불편 | 쉐어택 |
|---|---|---|---|---|
| 오송역 가는 길 | 충북대 3학년, 22세 | 충북대 → 오송역, KTX 시간 맞추기 | 혼자 18,850원 | 2명 9,500원 · 3명 6,300원 · 4명 4,800원 |
| 터미널 가는 길 | 오창 산단 직장인, 31세 | 오창 호수공원 → 고속·시외버스터미널, 금요일 귀향 | 혼자 16,690원 | 2명 8,400원 · 3명 5,600원 · 4명 4,200원 |
| 심야 귀가 | 오송 바이오 연구원, 28세 | 밤 KTX 도착, 버스 끊김, 오송역 → 고속·시외버스터미널(가경동) | 혼자 15,745원 (심야할증 별도) | 2명 7,900원, 귀로 면제 시 혼자 12,200원 |
| 기사 | 법인택시 기사, 50대 | 시내↔오송·오창, 하루 약 19.5회 | 읍·면 하차 뒤 빈 차 귀로, 연료·시간 손해 | 돌아가는 길에 손님과 수입 |
- 터미널은 시내(가경동)에 있다. 터미널↔시내는 할증이 없고, 터미널↔읍·면에서만 할증이 붙는다
- 기사 인터뷰 요지(청주 택시조합, 2026.11): 할증이 붙어도 수수료를 떼면 큰 소득은 없다 · 통합 과정에서 생긴 특이한 경우라 개선은 필요하다 · 그래도 할증이 없어지는 건 원치 않는다
- 멘트: 불편은 한 가지 상황에만 있지 않습니다. 이 네 사람의 불편이 다음 장부터 모든 전략의 출발점입니다.

## 3페이지. 원인 분석 및 해결 방안 — 손님이 없는 게 아니라, 빈 차와 엇갈린다
**원인** (정보공개청구 2026.4~9 운행 1,064만 건 팀 집계, TIMS 2025)
- **46.5%**: 청주 택시 운행거리 중 빈 차 비율
- **89명**: 시내→오송·오창 택시 100대당 시내로 가는 손님 (옥산 75 · 내수 74 · 강내 69 … 가덕 36 · 현도 31)
- **최대 82%**: 시간대를 맞춰도 오송에서 귀로 손님을 찾을 수 있는 비율
- **71%**: 읍·면 사이 이동 중 북서권(오송·오창·옥산·강내) 안 이동
- 빈 차 귀로 위험 지수: 오창 0.01 · 오송 0.19로 최저

**해결 방안: 3단계**
1. **거점 동승**: 오송역·터미널 등 메인 지점에서 모집, 2~4명이 요금을 나눔. 기사 앱 없이도 작동해 초기에 시작할 수 있다
2. **대중교통 정보**: 버스·열차 정보로 KTX 도착·막차에 맞춰 이동을 계획
3. **귀로 서비스(핵심)**: 내려준 택시가 시내 손님을 태워 돌아온다
   - 왕복 매칭: 시내→오송 호출과 오송→시내 손님을 짝지어 양쪽 할증 없음
   - 귀로 연계 결제(모의): 할증 포함 가승인, 하차 후 30분 안에 귀로 손님을 태우면 할증 빼고 결제
   - 노쇼: 약속하고 안 온 쪽이 할증분 부담
- 시 역할: 귀로가 확정된 운행은 할증 면제 고시
- 왜 3단계까지 가야 하나: 동승만으로는 승객 할증 부담이 3.7% 줄고 기사 수입이 0.45% 줄어든다(시뮬레이션). 동승은 시작점이고, 빈 차를 줄이는 귀로가 핵심이다
- 멘트: 동승으로 이용자를 모으고, 그 수요 위에 귀로 서비스를 얹습니다. 기사님이 처음부터 함께하기 어려운 초기 플랫폼의 현실을 반영한 순서입니다.

## 5페이지. MVP — 택시 앱을 바꾸지 않고, 할증 없는 길을 더한다
- 흐름: **모집 보기**(경로·시간·인원·조건) → **참여**(조건 확인) → **약속**(번호 없이 대화) → **송금**(택시 부르기 전 방장에게) → **탑승**(방장이 호출) → **도착**(아낀 돈 기록)
- 교통 탭: 오송역 도착 열차와 거점 주변 버스를 나눠 실시간으로 보여 주고, 출처와 확인 시각을 표시
- 기사 화면(시범): 내려준 곳 → 귀로 손님 → 태우면 빈 차 복귀와 수입 비교, 손님이 없거나 안 올 때의 가상 상황
- 기술: React 웹앱 · Supabase(로그인·DB·실시간 채팅) · Vercel 배포 · TAGO 실시간 API
- 시연: taxi-woad-seven.vercel.app, QR. 앱을 열면 자동 입장, 시연용 모집이 현재 시각에 맞춰 보이고 오송역 모집은 실제 KTX 도착을 따른다
- 호출 앱과 다른 점: 카카오T 등은 가까운 빈 차를 부르고 할증 그대로 / 반반택시는 같은 방향 동승, 동승 서비스 중단 후 B2B 전환(한경 2026.4) / 쉐어택은 돌아가는 빈 차와 손님의 방향을 맞추고 귀로 운행 할증 면제
- 안내: 결제·노쇼 수수료는 모의, 실제 배차·결제는 등록 호출 플랫폼 제휴 전제

## 6페이지. 경영전략 — STP / SWOT
**STP**
- S: KTX 이용 대학생·직장인 / 산단·바이오단지 출퇴근자 / 터미널 이용 읍·면 주민 / 심야 귀가자 / 읍·면 운행 택시 기사
- T: 1차 오송역 KTX 이용층(하루 1,793건 중 시내 방향 약 930건, 설문 응답자 84%가 대학생) → 2차 오창·터미널
- P: 차를 부르는 앱이 아니라 돌아가는 빈 차와 손님의 방향을 맞추는 할증 도우미

**SWOT**
- S: 공공 운행 데이터 근거, 손님·기사·시 모두 이득, 기사 없이도 동승으로 시작, 작동하는 앱
- W: 초기 이용자 확보, 호출 플랫폼 제휴 필요, 효과 검증이 설문·시뮬레이션 단계
- O: 9/28 개편 여론, 2028 오송·오창 해제 검토(충청매일 2026.8), KTX 수요
- T: 대형 호출 앱 진입, 업계 반발 가능성, 2028 해제 시 할증 절감 가치 축소 → 공차 감소 가치로 전환 필요

**4P(선택, 한 줄)**: Product 동승+정보+귀로 / Price 운임 n분의 1·귀로 매칭 수수료 / Place 웹앱·오송역 QR·산단·대학 / Promotion KTX 시간대·대학 제휴

## 8페이지. 사업성 검증 — 수요는 확인했고, 실측은 오송역 시범에서 검증한다
- **설문(N=57, 2026.10)**: 할증 때문에 택시 포기 63% · 이웃 읍·면 할증 불합리 74% · 없어지면 이용 증가 93% · 조건부 동승 의향 96% · 응답자 대학생 84%, 동 거주 77%
- **청주 택시조합 인터뷰(2026.11)**: 개선 필요엔 공감, 할증 폐지는 반대 → 할증을 없애는 대신 빈 차 귀로를 채워 수입을 지키는 쉐어택이 받아들일 수 있는 대안
