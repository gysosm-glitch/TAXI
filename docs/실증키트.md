# 쉐어택 실증 키트 (기사 인터뷰 · 시민 설문 · 현장 관찰)

> 목표: 발표 8장의 [5명]·[__명]을 채우고, "시뮬레이션뿐"이라는 지적에 실측으로 답한다. 기한 11/5.
> 원칙: 이름·전화번호는 받지 않는다(익명). 녹음은 동의할 때만. 결과는 숫자로 정리해 `docs/발표원고.md`에 넣는다.

## 1. 기사 인터뷰 (5명, 1명당 10분)
**장소**: 오송역 택시 승강장 대기 줄, 오창 호수공원 근처 · **시간**: 평일 오후(KTX 도착 사이 한산할 때)
**첫 마디**: "충북대 학생인데요, 오송·오창 택시 할증 관련해서 5분만 여쭤봐도 될까요? 이름은 안 받습니다."

| # | 질문 | 기록 |
|---|---|---|
| 1 | 시내에서 오송·오창에 손님을 내려 주면, 돌아갈 때 빈 차인 경우가 얼마나 되나요? (10번 중 몇 번) | __/10 |
| 2 | 손님을 내린 곳에서 다음 손님을 기다린다면 최대 몇 분까지 기다릴 수 있나요? | __분 |
| 3 | 앱에서 "지금 여기서 시내 가는 손님 2명 대기 중"이 보이면 받으시겠어요? | 예/아니오/조건 |
| 4 | 귀로 손님 할증을 면제하는 대신 1건당 얼마를 보전받으면 괜찮으세요? (2천/3천/4천원) | __원 |
| 5 | 지금 쓰는 호출 앱 수수료는 어느 정도이고, 부담되나요? | |
| 6 | 할증 때문에 손님과 실랑이하거나 손님이 줄었다고 느끼시나요? | |
| 7 | (자유) 이런 앱이 생기면 걱정되는 점은? | |

**정리 방법**: 1번 평균(빈 차 귀로 비율), 2번 중앙값(대기 의향), 3번 "예" 비율, 4번 최빈값 → 발표 6·7장 근거로 사용.

## 2. 시민 설문 (목표 50~100명, 구글 폼)
1. 연령대 (10대/20대/30대/40대/50대 이상) · 성별
2. 오송·오창과 시내를 택시로 오가나요? (주 1회 이상 / 월 1~3회 / 거의 안 탐)
3. 그때 할증(35%)을 알고 계셨나요? (알았다 / 몰랐다)
4. 같은 방향 사람과 택시를 나눠 탈 의향 (5점 척도)
5. 오송·오창에 손님을 내려 준 빈 택시를 앱으로 잡아 시내로 갈 수 있다면 쓰겠어요? (5점 척도)
6. 할증 면제분(약 4,300원) 중 매칭 수수료로 얼마까지 낼 수 있나요? (0 / 1천 / 2천 / 3천원 이상)
7. 동승할 때 가장 걱정되는 점 (안전 / 시간 지연 / 요금 분쟁 / 모르는 사람 / 기타)
8. 꼭 있었으면 하는 기능 (주관식)

**발표에 쓸 숫자**: 5번 4~5점 비율(이용 의향), 6번 2천원 이상 비율(**B안 수수료 2,622원 수용성 근거**), 7번 1위 우려.

## 3. 현장 관찰 (오송역, 15분 × 2회)
KTX 도착 직후 15분, 한산한 15분을 각각 기록한다.

| 시각 | 들어온 택시 (손님 태움/빈 차) | 나간 택시 | 승강장 줄 선 손님 수 | 메모 |
|---|---|---|---|---|
| | / | | | |

**발표에 쓸 숫자**: 손님을 내리고 바로 빈 차로 나간 택시 비율, KTX 도착 직후 줄 선 손님 수 → "손님과 빈 차가 엇갈린다"(4장)의 실측 증거.

## 4. 앱 시범 운영 기록
체험 계정 A·B와 팀원 계정으로 모의 이용 3회 이상 → 내 정보 › **시범 운영 현황**(가입·모집·매칭·아낀 돈) 화면을 캡처해 발표에 넣는다. 실제 탑승을 안 했으면 "모의 이용"으로 표기.
