# 쉐어택 PPT 구성안 (8장, 수상작 목차 기준)

> 2025 캡스톤 경진대회 수상작(Trip Talk 대상, 포도 가지 스모크칩·이음·비콘 길안내 최우수)의 공통 목차를 따랐다.
> 공통 흐름: **배경 → 페르소나 → 가치제안 캔버스 → 비즈니스 모델 캔버스 → MVP → 사업성 검증 → 경쟁 비교 → 운영·수익 계획**
> 숫자·출처는 [자료_출처_정리.md](자료_출처_정리.md)에서만 가져온다. `[ ]`는 팀이 채울 자리.

**표지 한 줄**: 쉐어택 (쉐어+택시) — 택시 앱과 함께 쓰는 할증 도우미: 빈 차로 돌아가는 택시와 시내 가는 손님을 잇는다
**목차(1장 왼쪽에)**: 01 연구 배경 · 02 페르소나·고객 여정 · 03 원인 분석 · 04 가치제안 캔버스 · 05 MVP·차별점 · 06 비즈니스 모델 · 07 사업성 검증 · 08 실행 계획

## 1장. 표지 + 연구 배경
- **문제 인식**: 같은 청주인데 동↔읍·면 택시는 **35% 복합할증**. 9/28 개편으로 같은 읍·면 안만 풀렸고, 시내↔오송·오창은 그대로
- **규모**: 읍·면 택시 승차의 **73%가 오송·오창** (하루 7,712건 중 5,643건, TIMS 2025)
- **아이디어 도출**: 시가 밝힌 할증 목적은 "승차난 방지와 **공차 손실 보전**" → 빈 차 귀로를 채우면 할증의 근거가 사라진다
- 그림: 청주 지도(시내→오송·오창 실선, 돌아오는 점선 = 빈 차), 쉐어택 로고, 목차

## 2장. 페르소나 + 고객 여정 지도
**손님 페르소나**: [이름], 28세, 오송 바이오단지 연구원 / KTX로 서울 출장 후 오송역 → 시내 귀가
- Pain: "오송역에서 시내까지 택시비가 1만 8천 원 가까이 나와요", 막차 끊기면 대안 없음
**기사 페르소나**: [이름], 50대 법인택시 기사
- Pain: "오송에 손님 내려 주면 거의 빈 차로 돌아와요" ← **인터뷰 인용 [ ]**
**고객 여정**(손님): KTX 도착 → 택시 줄 → 할증 요금 확인(불만 최고점) → 혼자 탑승 → 시내 도착
→ 쉐어택: KTX 도착 → 앱에서 같은 방향 모집·귀로 택시 확인(만족) → 나눠 타거나 면제 요금 → 도착
- **INSIGHT 요약**: ① 손님은 있는데 빈 차와 엇갈린다 ② 기사의 손해는 귀로 공차다 ③ 할증은 둘 다 불만

## 3장. 원인 분석 (데이터)
- **46.5%**: 청주 택시 운행거리 중 빈 차 비율 (TIMS 2025)
- **빈 차 귀로 위험 지수**: 오창 0.01 · 오송 0.19 · 옥산 0.38 … 가덕 0.88 → 가중치 6가지로 바꿔도 오창·오송·옥산은 늘 저위험 (순위 상관 0.92~0.99)
- **수요는 충분**: 오송읍 하루 3,025건, 오창읍 2,617건, 오송역 1,793건 중 **52%가 시내 방향**
- 결론 문장: "할증이 가장 많이 붙는 곳이, 빈 차로 돌아올 위험은 가장 낮다"
- 그림: 위험 지수 지도 + 막대그래프

## 5장. MVP + 차별점 (경쟁 비교)
- **할증 없이 가는 3가지 경우(팀원 제안)**: ① 왕복 매칭 성사 → 양쪽 할증 없음 ② 앱 호출·왕복 미성사 → 할증 포함 가승인, 하차 후 30분 안 귀로 손님 태우면 할증 빼고 최종 결제 ③ 앱 없이 현장 승차 → 미터기 요금. 노쇼 → 할증분을 안 온 쪽이 부담해 기사 손실 보전
- **앱 화면 3개**: ① 타기(지도·출발/도착·요금 비교) ② 기사(귀로 손님·수입 비교) ③ 첫 화면(이럴 때 쓰세요)
- 시연: taxi-woad-seven.vercel.app + QR, 체험 계정 A·B
- **경쟁 비교(전략 캔버스)** — 항목별 점수 그래프로
| 항목 | 카카오T 등 호출 앱 | 반반택시(동승) | 쉐어택 |

| 할증 | 그대로 | 그대로 | **귀로 운행 면제(시 정책 연동)** |
| 기사 | 호출 수수료 부담 | — | **귀로 수입 증가** |
| 지역 특화 | 전국 일반 | 서울 심야 | **청주 읍·면 할증 구간** |

## 8장. 실행 계획 (운영·법·기대효과)
- **로드맵**: 1단계 오송역·KTX 도착 시간대 집중 → 2단계 승강장 택시 단체 1곳 제휴 → 3단계 오송·오창 2개 거점 → 4단계 귀로 할증 면제 고시 건의
- **법**: 택시발전법 시행규칙 제11조의2(본인 확인·좌석 고지·동성끼리) 준수 / 선례: 반반택시 2019 실증특례 → 2022 합법화 / 제휴 또는 규제샌드박스
- **SWOT** (작게)
  - S 데이터 근거, 시 정책 연동, 기사·손님 모두 이득 / W 초기 이용자 확보, 제휴 필요
  - O 9/28 개편 여론, 반반택시 선례, KTX 수요 / T 대형 호출 앱 진입, 업계 반발
- **기대 효과**: 손님 할증 부담↓, 기사 공차↓·수입↑, 시 보전 예산↓, 탄소↓(빈 차 주행 감소)
- **한계**: 시뮬레이션 기반, 요율 보도 기준, KTDB 2024 평일 자료
- 마무리 문장 + QR: **"빈 차 귀로를 채우면, 할증의 이유가 사라진다"**

## 수상작에서 따라 할 디자인 포인트
- 장마다 **번호 + 짧은 제목**(01 연구 배경 …), 첫 장 왼쪽에 **목차**
- 캔버스류(가치제안·BMC)는 **표/도식 그대로** 넣는다 — 심사위원이 찾는 틀
- 페르소나는 **얼굴 일러스트 + 말풍선 인용**, 인터뷰 인용을 말풍선에
- 숫자는 크게, 문장은 짧게. 앱 화면은 **휴대폰 틀** 안에
- 색은 쉐어택 색(진초록 #0F2A22 · 초록 #1D9E75 · 호박색 #F2A93B)으로 통일
