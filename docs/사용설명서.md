# 같이타 청주 사용 설명서

**접속:** https://taxi-woad-seven.vercel.app
→ 휴대폰 메뉴에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 시작
- **체험 계정 A·B**: 바로 들어가기 (시연용)
- **이메일 회원가입**: 닉네임·성별·휴대폰 입력 후 시작

## 탭 5개
| 탭 | 하는 일 |
|---|---|
| 홈 | 아낀 돈, 지금 모집, 다음 버스·막차, 운영 현황 |
| 같이타기 | 출발지 고르기 → 모집 열기 / 참여. 읍·면→시내 모집은 **귀로 매칭** 표시 |
| 기사 | 손님 내린 곳 고르기 → 시내행 대기 손님, 빈 차 복귀 vs 귀로 손님 수입 비교 |
| 교통 | 실시간 버스, 막차, 오송역 KTX 도착 |
| 내 정보 | 내 평점, 의견 보내기, 로그아웃 |

## 같이 타는 법
1. **같이타기** → 출발지 고르기
   - 추천 스팟(오송역 등) 또는 **📍 다른 곳에서 출발**(현재 위치·읍면동)
2. **새 모집 열기**: 만날 곳 · 목적지 · 출발 시각 · 인원
   - 혹은 열려 있는 모집에 **참여**
3. 인원이 차면 알림 → **탑승 전 안내**(동승자·좌석) 확인
4. 대표 1명이 택시 호출 (카카오T 열기)
5. 도착하면 **도착했어요** → 별점

## 알아 둘 것
- 같은 성별끼리만 보이고 함께 탈 수 있어요 (법령)
- 시범 서비스예요. 실제 결제는 없어요
- 불편한 점은 **내 정보 › 의견 보내기**
