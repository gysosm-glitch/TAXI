# 쉐어택 사용 설명서

**접속:** https://taxi-woad-seven.vercel.app
→ 휴대폰 메뉴에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 시작
- **체험 계정 A·B**: 바로 들어가기 (시연용). 탭 두 개에서 동시에 쓸 수 있고, 탭을 닫거나 30분 동안 쓰지 않으면 로그아웃돼요. 기록은 다음에 들어올 때 지워지고, 다시 찍을 때는 **내 정보 › 체험 기록 지우고 다시 하기**
- **이메일 회원가입**: 닉네임·성별·휴대폰 입력 후 시작

## 탭 3개
| 탭 | 하는 일 |
|---|---|
| 타기 | 출발지·목적지 → 요금 비교 → 모집 열기 / 참여. 막차·KTX 안내도 여기서 |
| 기사 | 손님 내린 곳(📍 내 위치) → 시내행 귀로 손님, 빈 차 복귀 vs 귀로 손님 수입 비교, **가상 상황으로 해 보기**(귀로 손님 있음·KTX 대기·노쇼·손님 없는 곳) |
| 내 정보 | 아낀 돈, 운영 현황, 내 평점, 의견 보내기, 로그아웃 |

## 같이 타는 법
1. **모집**: 타기 → 출발지와 도착지 → **모집 열기** → 만날 곳, 몇 분 뒤에 탈지, 몇 명(2~4명)
2. **참여**: 걸어서 15분(1km) 안의 사람이 **내 주변 모집**에서 방향을 보고 **참여**
   - 인원이 덜 차도 모집자가 **이 인원으로 출발**을 누를 수 있어요
3. **약속**: 내 모집 카드의 대화로 시간과 만날 곳을 맞춰요 (휴대폰 번호는 안 보여요)
4. **탑승**: 모집자가 **택시 부르기**
5. **평가**: 내리면 **도착 · 평가하기** → 별점, 아낀 돈 기록

## 알아 둘 것
- 같은 성별끼리만 보이고 함께 탈 수 있어요 (법령)
- 시범 서비스예요. 실제 결제는 없어요
- 불편한 점은 **내 정보 › 의견 보내기**
