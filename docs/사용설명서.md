# 쉐어택 사용 설명서

**접속:** https://taxi-woad-seven.vercel.app (QR: `docs/qr_쉐어택.png`)
→ 아이폰 Safari: 공유 › **홈 화면에 추가** / 안드로이드 Chrome: 메뉴(⋮) › **홈 화면에 추가**. 주소창 없이 앱처럼 열려요.

## 시작
- **로그인 없이 둘러보기**: 요금 비교·기사 화면을 바로 봐요
- **쉐어택 알아보기**: 할증을 없애는 방법과 근거 데이터(2026 실측 포함)
- **체험 계정 A·B**: 바로 들어가기 (시연용)
- **이메일 회원가입**: 닉네임·성별·휴대폰 입력 후 시작

## 탭 3개
| 탭 | 하는 일 |
|---|---|
| 타기 | 출발·도착(주소·장소 검색, 내 위치, 집·회사·최근) → 요금 비교 → 할증 없이 가기(시내→읍·면일 때) → 주변 모집 참여·모집 열기. 버스·막차·KTX도 여기서 |
| 기사 | 손님 내린 곳(내 위치 또는 읍·면) → 시내행 귀로 손님, 빈 차 복귀 vs 귀로 손님 수입, 2026 실측 택시 흐름(시간대 막대) |
| 내 정보 | 아낀 돈, 시범 운영 현황, 평점, 쉐어택 알아보기, 안전 · 개인정보, 의견 보내기, 로그아웃 |

## 같이 타는 법
1. **타기** → 출발 칸을 눌러 검색하거나 오른쪽 위 **위치 버튼**(내 위치)
2. 도착 칸 또는 **어디로 가세요?** 칩에서 목적지 → 요금 확인 → **모집 열기**(출발 시각·만날 곳) 또는 열려 있는 모집에 **참여**
3. 인원이 차면 화면 위 알림 → **탑승 전 안내**(동승자·좌석) 확인
4. 대표 1명이 택시 호출 (**택시 부르기**), 필요하면 **지인에게 알리기**·**112 긴급 신고**
5. 도착하면 **도착했어요** → 별점(왕복 매칭은 '안 왔어요' = 노쇼)

## 할증 없이 가기 (시내 → 오송·오창 등)
1. **왕복 매칭**: 도착지에서 시내로 갈 손님을 미리 구함 → 양쪽 할증 없음 (성별 제한 없음)
2. **귀로 연계 결제(모의)**: 할증 포함 가승인 → 30분 안 귀로 손님 태우면 할증 빼고 결제
3. **앱 없이 현장 승차**: 미터기 요금

## 알아 둘 것
- 일반 모집은 같은 성별끼리만 보이고 함께 탈 수 있어요 (법령)
- 시범 서비스예요. 실제 결제·배차는 없어요
- 화면은 휴대폰의 다크 모드를 따라가요
- 불편한 점은 **내 정보 › 의견 보내기**
