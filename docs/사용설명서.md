# 쉐어택 사용 설명서

**접속:** https://taxi-woad-seven.vercel.app
→ 휴대폰 메뉴에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 시작
- **체험 계정 A·B**: 바로 들어가기 (시연용)
- **이메일 회원가입**: 닉네임·성별·휴대폰 입력 후 시작

## 탭 3개
| 탭 | 하는 일 |
|---|---|
| 타기 | 지도에서 출발지(📍 내 위치·추천 스팟·지도 누르기) → 목적지 → 요금 비교 → 모집 열기 / 참여. 버스·막차·KTX도 여기서 |
| 기사 | 손님 내린 곳(📍 내 위치) → 시내행 귀로 손님, 빈 차 복귀 vs 귀로 손님 수입 비교 |
| 내 정보 | 아낀 돈, 운영 현황, 내 평점, 의견 보내기, 로그아웃 |

## 같이 타는 법
1. **타기** → 지도 오른쪽 아래 **📍 버튼**(내 위치) 또는 위쪽 **출발 › 바꾸기**
   - 내 위치 800m 안에 추천 스팟이 있으면 그곳이 출발지로 잡혀요
2. **어디로 가세요?**에서 목적지 → 요금 확인 → **모집 열기**(출발 시각·만날 곳)
   - 혹은 열려 있는 모집에 **참여**
3. 인원이 차면 알림 → **탑승 전 안내**(동승자·좌석) 확인
4. 대표 1명이 택시 호출 (**택시 부르기** 버튼)
5. 도착하면 **도착했어요** → 별점

## 알아 둘 것
- 같은 성별끼리만 보이고 함께 탈 수 있어요 (법령)
- 시범 서비스예요. 실제 결제는 없어요
- 불편한 점은 **내 정보 › 의견 보내기**
