# 쉐어택 사용 설명서

**접속:** https://taxi-woad-seven.vercel.app
→ 휴대폰 메뉴에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 시작
- **시작**: 체험 계정으로 들어가요. 로그아웃하기 전까지 다음에 열면 자동으로 들어오고, 기록은 그때 지워져요
- **이메일 회원가입**: 닉네임·성별·휴대폰 입력 후 시작

## 탭 4개
| 탭 | 하는 일 |
|---|---|
| 타기 | 지금 모집 중인 칸 보기, 조건이 맞으면 참여, 없으면 모집 열기 |
| 교통 | 열차, 터미널 고속·시외버스, 시내버스 정보 (출처·확인 시각 표시) |
| 기사 | 귀로 손님을 태우면 수입이 어떻게 달라지는지 체험 (시범) |
| 내 정보 | 아낀 돈, 운영 현황, 의견 보내기, 로그아웃 |

## 같이 타는 법
1. **보기**: 타기 탭의 **지금 모집 중**에서 경로·시간·인원·조건을 봅니다. 출발지와 도착지를 고르면 맞는 칸만 남아요
2. **참여**: **참여**를 누르고 조건을 확인한 뒤 **탑승**
3. **약속**: 내 모집 카드의 대화로 시간과 만날 곳을 맞춥니다 (휴대폰 번호는 안 보여요)
4. **송금**: 인원이 모이면 1인 금액을 방장에게 먼저 보내고 **송금 완료**를 누릅니다. 앱은 돈을 보관하지 않아요
5. **탑승**: 방장이 택시를 부르면 함께 탑니다
6. **도착**: 내리면 **도착**를 눌러 아낀 돈을 기록합니다

'시연' 표시가 붙은 모집은 앱 소개용 가상 모집입니다. 시간은 지금 시각에 맞춰 움직이고, 오송역 모집은 실제 KTX 도착 시각을 따릅니다.

## 알아 둘 것
- 같은 성별끼리만 보이고 함께 탈 수 있어요 (법령)
- 시범 서비스예요. 실제 결제는 없어요
- 약속에 늦거나 술에 많이 취했으면 방장이 탑승을 거절할 수 있어요
- 불편한 점은 **내 정보 › 의견 보내기**
